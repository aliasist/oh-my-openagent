## Users

Developers and AI researchers who want a multilingual AI agent harness — running AI agents with support for multiple languages and frameworks.

## Product Purpose

Oh My OpenAgent is a multilingual AI agent harness — providing a framework for running AI agents with support for multiple languages and integration patterns. Users can deploy and manage AI agents across different environments.

## Positioning

A multilingual AI agent harness — not tied to one language or framework, but a flexible platform for AI agent deployment.
